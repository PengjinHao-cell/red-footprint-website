# 尚未开发阶段提示词导航

本目录只服务于尚未开发的阶段。新版精简计划是唯一执行依据：

- `PLAN/09B-production-content-and-cloudbase.md`

## 使用方法

1. Task 1 已完成；从 `09B/02-globe-from-flat-map.md` 开始，把其中“实施提示词”完整复制到一个新的 Codex 任务。
2. 实施任务交付后，把同文件的“验收提示词”复制给验收任务。
3. 验收通过：打开该文件“通过后”指向的下一份文件，复制下一阶段实施提示词。
4. 验收不通过：复制“未通过时的修复提示词”，并把验收官的实际问题原文放进指定位置；修复完成后仍使用原阶段验收提示词复验。
5. 不得跳过阶段。Task 6 涉及媒体上传，Task 7 涉及 GitHub 绑定与部署，必须遵守各自独立授权条件。

## 全局纪律

- 当前分支为 `main`；每个 Task 只建一个独立本地提交，不 amend、不 push。
- 不使用子代理、多代理、委派或并行代理。
- 开始前检查工作区；保留用户素材和无关改动，不删除、不移动、不暂存。
- 严格读取对应 PLAN 的完整 Task；若本提示词与 PLAN 冲突，以 PLAN 和较新的 09B 架构决定为准，并停止说明冲突，不自行扩展范围。
- 实施采用 TDD；验收必须独立复跑命令，不能只相信实施报告。
- CloudBase 固定环境 `red-footprint-preview-d5322636bd`，架构为静态托管加云存储，不使用数据库、云函数、云托管容器、鉴权或运行时 API。
- 任何上传、资源创建、权限修改、对象删除、GitHub 绑定和部署，均需该动作的单独明确授权。
- 地图不再设置审图门禁；`check:map` 只做来源、资源、点位和视觉完整性检查。不得声称三维衍生地图取得新的审图批准。

## 顺序

`09B/02` → `03` → `04` → `05` → `06` → `07`

Task 6 的提示词不构成上传授权；Task 7 的提示词不构成 GitHub 绑定、首次部署或最终公开发布授权。
