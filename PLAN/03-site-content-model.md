# Plan 03 — 八景点内容模型

> 建议分支：`codex/03-site-content-model`  
> 前置依赖：Plan 01  
> 可并行：可与 Plan 02、04 同时开发

## 目标

建立八个景点的强类型内容契约和资料交付规范。任何缺少权威来源、视频字幕或必要字段的数据都不得进入生产构建。

## 固定景点

淮北抗日民主根据地纪念馆、雨花台烈士陵园、渡江胜利纪念馆、四行仓库、一大会址、江上清烈士史料陈列馆、扬州革命烈士陵园、中国共产党代表团梅园新村纪念馆。除最后一项外，正式展示名称上线前仍需依据权威资料核验。

## 数据字段

每条记录必须包含：ID、正式名称、简称、省市区、地址、经纬度、开放信息、预约方式、参观提示、官方称号、历史、人物、精神、感悟、头图、头图焦点、3–5张照片、视频地址、封面、字幕和至少一条权威来源。

## 执行步骤

- [ ] 先写失败测试：有效八条通过，七条失败，重复名称失败，HTTP 视频失败，空来源失败。
- [ ] 使用 Zod 实现 `siteSchema` 和集合级 `loadSites`。
- [ ] 强制 `province` 只能是“江苏省”或“上海市”。
- [ ] 强制视频使用 HTTPS，图片数为 3–5，来源至少一条。
- [ ] 在 `docs/content-intake.md` 写清文件命名、WebVTT字幕和权威来源要求。
