# 八景点内容资料交付规范

本规范用于收集后续生产资料。当前阶段不创建生产地点 JSON；`src/test/fixtures/sites.ts` 中的记录全部是合成测试资料，不得复制到生产构建。

## 八个地点交付清单

以下是项目方提供的工作名称：

1. 淮北抗日民主根据地纪念馆
2. 雨花台烈士陵园
3. 渡江胜利纪念馆
4. 四行仓库
5. 一大会址
6. 江上清烈士史料陈列馆
7. 扬州革命烈士陵园
8. 中国共产党代表团梅园新村纪念馆

除“中国共产党代表团梅园新村纪念馆”外，其余七个工作名称都必须在生产资料上线前依据权威来源核验正式展示名称。工作名称不能直接当作已核验的正式名称。

每个地点须一次性交付下列内容：

- 唯一英文小写 ID，只使用 `a-z`、`0-9` 和连字符；
- 已核验的正式名称、页面简称；
- 省、市、区、完整地址和经纬度；
- 开放信息、预约方式、参观提示和官方称号；
- 历史、人物、精神与团队寻访感悟正文；
- 一张代表性头图及其横向、纵向焦点百分比；
- 三至五张画廊照片；
- 一条讲解视频、独立视频封面和一个 WebVTT 字幕文件；
- 至少一条带名称和有效 URL 的权威来源。

省级行政区只能填写“江苏省”或“上海市”。八个地点的 ID 和正式名称必须分别唯一；只有恰好八条完整、唯一的记录才能进入生产构建。

## 文件命名与媒体规格

先为每个地点确定稳定的 `site-id`，全部文件使用同一个 ID 前缀，文件名不使用空格：

```text
<site-id>-hero.webp
<site-id>-photo-01.webp
<site-id>-photo-02.webp
<site-id>-photo-03.webp
<site-id>-video.mp4
<site-id>-video-poster.webp
<site-id>-captions.vtt
```

画廊照片必须为三至五张，并按展示顺序连续编号；头图不计入这三至五张。建议网页交付图片使用 WebP，需保留摄影原始文件；暂不适合转为 WebP 时可交付高质量 JPEG。竖版实拍图优先保留 9:16 构图，不拉伸、不加黑边，并为头图单独提供 `0–100` 的横向和纵向焦点值。

视频文件使用 MP4/H.264、9:16、720×1280、25 fps，音频使用 AAC；建议单条约 60 秒、15–25 MB，并启用 `faststart`。生产视频地址必须以 `https://` 开头，HTTP 地址会被数据校验拒绝。

## WebVTT 字幕

每条视频必须配套一个 UTF-8 编码的 `.vtt` 文件，第一行必须是 `WEBVTT`。时间轴使用 `HH:MM:SS.mmm --> HH:MM:SS.mmm` 格式，字幕顺序不得重叠或倒退；字幕内容应覆盖完整口播并由人工校对人名、地名、年代和标点。字幕文件与视频使用同一 `site-id`，交付前须在目标视频上检查同步、静音播放可读性和移动端显示效果。

## 权威来源与事实核验

可接受的首选来源包括场馆官方网站或官方发布、政府部门网站、现场展板或馆方资料、正式出版的权威文献。自媒体文章、聚合旅游页面、搜索摘要和无法追溯出处的转载不能作为事实字段的唯一来源。

每条来源记录至少包含来源名称和可访问 URL；资料交付表还应记录发布机构、页面或文献标题、访问日期、该来源支持的具体字段，以及必要的页面存档或现场资料照片。现场展板和纸质资料可作为补充证据，但每条生产记录仍必须至少提供一个可追溯的有效来源 URL。

以下事实字段必须逐项与来源核对，不能依靠常用叫法、地图搜索结果或个人记忆填写：

- 正式名称与简称；
- 省、市、区、地址和经纬度；
- 开放信息、预约方式、参观提示与官方称号；
- 历史年代、事件、人物身份及事迹；
- 媒体中的人名、地名、年代、建筑或展陈说明。

经纬度须与已核验地址及合规地图来源交叉检查。开放和预约信息可能变化，交付时必须记录核验日期，并在正式发布前复核。

## 进入生产构建的门槛

资料负责人须保存“字段—来源”对应关系，内容审核人须确认八条记录均完整且来源可追溯。任何未经权威来源核验的正式名称、地址、经纬度、开放信息、历史事实或人物信息，任何缺少字幕、媒体文件或来源 URL 的记录，都不得写入生产数据或进入生产构建。不得用测试 fixture、猜测值或占位文案绕过该门槛。
