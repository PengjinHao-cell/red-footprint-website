# 景点统一媒体轮播设计

日期：2026-08-20
状态：交互讨论已确认，待用户审阅书面设计

## 1. 背景与目标

甲方重新提出景点媒体页构想：用户点击地球红心并完成镜头飞行后，详情首项显示视频，向左滑动依次查看该景点照片。原设计中相互分离的照片画廊与视频板块，调整为一条连续媒体序列。

本设计只改变详情媒体的组织和交互，不改变八景点、镜头飞行、正文模块、静态站部署或视频云存储方案。

## 2. 已确认决策

- 采用单一沉浸式媒体轮播，不使用视频/照片双标签，也不使用视频固定加缩略图带。
- 每次打开详情从视频封面开始，顺序固定为“视频、照片 1、照片 2……”。
- 媒体序列不循环，最后一张不会跳回视频。
- 媒体区之后纵向排列历史、人物、精神、感悟、参观信息和权威来源。
- 每处允许一至五张照片；超过五张时预选五张，原图全部保留。
- 视频播放期间锁定横向滑动，暂停、结束或失败后恢复。

## 3. 页面结构

详情从上到下包含：

1. 景点名称、城市、属性标签和关闭按钮；
2. 统一媒体轮播；
3. 页码、媒体类型和首次滑动提示；
4. 基础信息；
5. 历史印记；
6. 人物故事；
7. 精神传承与研学感悟；
8. 参观信息与权威来源。

手机端使用近全屏详情面板。电脑端使用宽详情面板或右侧详情层，媒体区位于上部。页面纵向滚动与媒体横向滑动必须进行方向判定，斜向手势不得轻易误触换页。

## 4. 输入与可访问性

- 手机：左右滑动切换媒体，屏幕边缘系统返回手势不得被强行拦截。
- 电脑：支持拖动、左右箭头和键盘方向键。
- 视频获得焦点时，空格键仍控制播放与暂停，轮播不得抢占。
- `Escape` 关闭详情，并将焦点恢复到触发详情的点位。
- 页码和媒体类型变化使用可访问的状态文本表达，但不得频繁打断屏幕阅读器。
- 操作系统启用减少动态效果时，取消惯性和装饰过渡，保留直接切页。

## 5. 播放状态

- 视频不自动播放，初始只显示封面与播放按钮。
- 未播放时允许切换到照片。
- 开始播放后锁定横向滑动与轮播箭头，避免误触离开。
- 暂停、播放结束或播放失败后恢复切换。
- 关闭详情或离开视频项时必须暂停并停止声音。
- 重新打开同一景点时回到视频封面页，不续播上次进度。

## 6. 图片展示与预选

- 横图和竖图均可进入轮播，使用 `object-fit: contain` 完整展示，不拉伸、不强裁主体。
- 空余区域使用符合 B 视觉系统的深棕或柔和衬底，不使用纯黑太空背景。
- 图片多于五张时按以下顺序预选：景点识别度、构图与清晰度、现场实践记录、展陈或史料内容、画面差异性。
- 排除严重模糊、过曝、主体截断和高度重复的照片。
- 视觉预选只判断质量与多样性，景点归属和历史含义必须人工复核。
- 当前素材允许一至五张，照片不足三张不再阻止构建。

## 7. 素材整理

`Videos/` 保留为原始交付归档，不直接作为生产 URL。入选图片生成标准化网页副本，使用稳定英文景点 ID 和顺序文件名，例如：

```text
public/media/sites/sihang-warehouse/photo-01.webp
public/media/sites/sihang-warehouse/photo-02.webp
```

网页图片建议输出 WebP，长边约 1920px、质量约 82；原图不覆盖。ZIP 仅作为交付备份，不进入构建。视频正式上线仍使用 CloudBase 或腾讯云 COS 的 HTTPS URL，不提交普通 Git 历史。

扬州革命烈士陵园当前视频为 `Videos/扬州革命烈士陵园/8月20日.mp4`，当前磁盘大小约 101MB。发布前仍需检查编码、码率、`faststart` 和目标网络下的首帧等待时间。

## 8. 数据契约

每处景点仍恰好对应一条视频，并包含一至五张图片。运行时将现有字段转换为统一媒体序列：

```ts
[
  { type: 'video', src, poster, captions },
  { type: 'image', src, alt },
  { type: 'image', src, alt },
]
```

图片替代文本描述可见主体，不能仅写“照片 1”。涉及人物身份、历史事件或场馆性质的描述必须经过来源核验。

## 9. 加载与失败处理

- 首页不请求完整视频；详情打开后仅预载视频 metadata。
- 图片仅加载当前项，并预取相邻一项。
- 图片失败时显示带景点名称的米白占位图。
- 视频失败时显示重新加载按钮，但不阻止用户查看照片和正文。
- 弱网优先显示标题、视频封面和正文骨架。
- 某处只有一张照片时仍使用相同轮播，不显示无意义的额外分页点。

## 10. 测试与验收

- 八个地点各有一条视频和一至五张图片。
- 视频是每条序列的第一项。
- 手机滑动、电脑箭头、拖动和方向键均能切换。
- 视频播放期间无法横向切页，暂停后恢复。
- 离开视频、关闭详情后无残留声音。
- 最后一张不循环回视频。
- 横图、竖图均不拉伸和错误裁切。
- 纵向正文滚动与横向媒体手势不会明显冲突。
- 图片或视频失败不会导致详情页崩溃。
- 390×844、768×1024、1366×768 和 1920×1080 均完成视觉检查。
