# “青春寻访·红色足迹”长三角专题网站设计

日期：2026-08-20  
状态：已通过交互讨论，待用户审阅书面设计

## 1. 项目目标

为南京晓庄学院暑期社会实践团队制作一套面向公众传播与学校答辩展示的沉浸式静态网站。网站聚焦长三角专题中的江苏、上海八处红色文化地标，通过可交互 3D 地球、镜头飞行动画、实地照片、讲解视频和史实文案呈现实践成果。

网站优先保证手机端链接访问体验，同时兼容电脑投屏。二维码仅作为正式链接的可选传播形式，不属于网站核心功能。

## 2. 已确定范围

### 2.1 景点与媒体

网站设置八个红色点位，每个点位对应一处景点、一组照片和一条约 60 秒的竖版讲解视频：

1. 淮北抗日民主根据地纪念馆
2. 雨花台烈士陵园
3. 渡江胜利纪念馆
4. 四行仓库
5. 一大会址
6. 江上清烈士史料陈列馆
7. 扬州革命烈士陵园
8. 中国共产党代表团梅园新村纪念馆

上述名称来自项目方素材。正式上线前，除第八项已由项目方明确全称外，其余名称仍须以场馆官网、政府部门或现场资料核验正式名称，不得凭常用简称推断。

### 2.2 地理范围

专题名称采用“长三角红色足迹”，实际点位集中于江苏、上海。本网站不得宣称已经覆盖上海、江苏、浙江、安徽全部区域，建议统一使用“聚焦长三角地区，寻访江苏、上海具有代表性的红色文化地标”等准确表述。

### 2.3 不在范围内

- 数据库与服务端业务接口
- 内容管理后台
- 用户注册、登录、评论或投稿
- 在线支付
- 实时定位与导航
- 将二维码作为独立网站功能开发；正式网址确定后可使用外部工具生成对应二维码

## 3. 视觉方向

采用已确认的 B 方案“青春人文感”：

- 主色为米白、砂岩、砖红和深棕；
- 页面背景保持明亮，避免黑色太空或冷峻科技展厅风格；
- 3D 地球使用暖色材质、适度阴影和红色点位；
- 排版带有史料纸张和青年纪实气质；
- 动画轻柔、克制，服务于内容，不追求炫技；
- 红色用于点位、按钮与重点提示，避免大面积高饱和红色造成视觉疲劳。

## 4. 信息架构

网站采用单页沉浸式结构，不设置传统多页面导航：

1. 欢迎加载页
2. 3D 长三角红色地图
3. 点击红色点位
4. 镜头飞向目标城市
5. 打开景点详情面板
6. 先浏览视频与照片组成的连续媒体序列，再向下阅读史实信息
7. 关闭面板并返回地球继续探索

主要组件：

- `WelcomeScreen`：团队名称、学校名称、简短导语、加载反馈和“开启寻访”按钮。
- `GlobeScene`：3D 地球、长三角视觉聚焦、旋转与缩放。
- `LocationMarker`：八个跳动红色点位及浏览状态。
- `CameraFlight`：目标点位的镜头旋转、拉近和返回动画。
- `SiteDetailPanel`：景点详情容器。
- `MediaCarousel`：将一条视频与一至五张照片组成连续媒体序列。
- `VideoPlayer`：轮播首项中的封面、字幕视频及播放反馈。
- `JourneyProgress`：显示“已点亮 N/8 处红色坐标”。
- `sites.json`：八处景点的本地结构化资料。

## 5. 景点详情设计

### 5.1 头图

每个详情面板顶部使用该景点的一张代表性实拍照片作为沉浸式头图。景点所属城市、正式名称和属性标签叠加在图片底部，并设置砖红至透明的渐变遮罩保证文字对比度。

手机端头图约为 4:5，优先保留 9:16 原图主体；电脑端可适当降低高度，但不得将竖版照片强行裁成过扁横幅。图片焦点位置需要按景点单独配置。

### 5.2 内容模块

每个景点统一包含：

1. 媒体序列：视频封面、约 60 秒讲解视频、字幕和一至五张精选实拍图片。
2. 基础信息：正式名称、地址、开放时间、预约方式、参观提示和官方称号。
3. 历史印记：历史由来、年代背景和关键事件。
4. 人物故事：代表人物或英烈事迹。
5. 精神传承：红色精神、时代价值与研学感悟。
6. 史料来源：场馆官网、政府资料、现场展板或权威文献。

详情首屏将“云端宣讲”和“寻访影像”合并为一条连续媒体序列，固定顺序为“视频、照片 1、照片 2……”。手机端使用左右滑动，电脑端同时提供拖动、左右箭头和方向键。视频开始播放后锁定横向滑动，暂停或播放结束后恢复；切换离开视频时必须暂停播放。序列到达最后一张后不循环返回视频。

媒体区下方显示当前页码、媒体类型和首次操作提示“左滑查看寻访照片”。详情正文位于媒体区下方，用户纵向滚动阅读。照片多于五张时按景点识别度、画面质量和内容多样性预选五张，原始素材全部保留并由项目方复核入选清单。

模块资料缺失时隐藏对应模块，不展示空标题或占位文案。

## 6. 核心交互

点击点位后的标准流程：

1. 暂停地球自动旋转并锁定其他点位交互。
2. 当前点位红色光圈向外扩散。
3. 镜头轻微拉远后旋转至目标方向。
4. 镜头平滑拉近，显示“正在前往【景点名称】”。
5. 约 1.8 至 2.5 秒后从底部升起详情面板。
6. 关闭面板后镜头返回长三角总览并恢复交互。

动画过程中禁止重复触发点位。操作系统启用“减少动态效果”时，使用短淡入淡出替代完整飞行动画。

浏览过的点位从跳动亮红变为稳态暗红，浏览进度只保存在当前浏览器，不上传任何个人信息。

## 7. 技术架构

采用方案 A：

- React + Vite：前端工程与构建
- Globe.gl + Three.js：3D 地球、点位和材质渲染
- GSAP：镜头和界面转场
- 本地 JSON：景点结构化资料
- GitHub：源代码版本管理
- CloudBase 或 EdgeOne Pages：前端自动构建与发布
- CloudBase 云存储或腾讯云 COS：视频文件托管

网页代码、文字、图片和视频封面随 GitHub 自动部署。大体积视频不提交普通 Git 历史，而作为同一网站的静态媒体上传至云存储；`sites.json` 保存视频地址。此安排不引入数据库或后台。

## 8. 视频规范

- 数量：八条，每个景点一条
- 时长：约 60 秒
- 画幅：9:16
- 分辨率：720×1280
- 容器与编码：MP4 / H.264
- 帧率：25 fps
- 音频：AAC，96 至 128 kbps
- 单条目标体积：15 至 25 MB
- 必须包含字幕和独立封面
- 使用 `faststart`，支持边下载边播放

推荐压缩基线：H.264 `CRF 22`、`preset slow`、最大视频码率 2.5 Mbps、缓冲 5 Mbps、像素格式 `yuv420p`、AAC 128 kbps。若剪辑软件导出的文件已在目标体积内且画质合格，不进行二次压缩。

## 9. 地图合规

地图合规是硬性发布门槛：

- 视觉草图中的抽象陆块不得用于正式产品。
- 不手绘、简化、猜测或自行修改中国国界与行政区划。
- 使用自然资源主管部门提供的标准地图，或具有合法审图号的互联网地图服务与数据。
- 出现中国全图时完整、准确表示中华人民共和国疆域。
- 不随意删除、裁切、变形标准地图边界。
- 在页面适当位置标注地图数据来源及审图号。
- 景点所属行政区与经纬度分别核查。
- 上线前执行专门的地图合规验收。

Globe.gl 与 Three.js 仅负责渲染和动画，地图纹理、疆域轮廓与行政区划必须来自合规数据源，不采用来源不明的 GeoJSON。

## 10. 加载、异常与降级

- 地球加载期间保留欢迎页和明确的加载反馈。
- 3D 资源加载失败时切换为八景点列表，全部内容仍可浏览。
- 图片加载失败时显示带景点名称的米白占位图。
- 视频加载前先显示封面和加载状态；播放失败时提供重新加载。
- 视频播放期间锁定媒体区横向滑动，暂停、结束或失败后恢复。
- 首页不请求八条完整视频，进入对应景点后才加载目标视频。
- 图片使用网页压缩版本与懒加载，只预取当前项的相邻图片，原图单独归档。
- 弱网时优先加载地球、标题与头图，媒体图片和视频延后。
- 设备性能不足时降低渲染像素比、材质分辨率和动画复杂度。
- 静音浏览时依靠字幕完整传达视频信息。

## 11. 部署方案

开发预览可使用 Railway 新加坡节点。正式版本优先考虑支持 Git 仓库自动部署的腾讯云 CloudBase 或 EdgeOne Pages，视频存储使用 CloudBase 云存储或腾讯云 COS。

正式部署到中国大陆节点时，应使用已完成 ICP 备案的自定义域名。学校性质的公开成果站优先使用学校或项目方提供的备案域名、子域名或服务器资源。

## 12. 验收标准

- 八个点位、八处景点和八条视频一一对应。
- 正式场馆名称、地址、开放信息与史实均有权威来源。
- 中国地图、行政区划、地图来源和审图号合规，不存在疆域歧义。
- 每处使用一至五张精选照片；所有图片方向正确，无拉伸或明显错误裁切。
- 八条视频均可播放，字幕同步，封面正确。
- 手机端旋转、缩放、点位点击、媒体左右滑动与详情纵向滚动正常。
- 视频播放期间不因横向误触切页，暂停后可继续滑动；最后一张不循环回视频。
- 电脑端适合答辩投屏，信息不会被过度放大或裁切。
- 微信内置浏览器、Safari 与 Chrome 均可正常访问。
- 弱网和 3D 加载失败时存在明确反馈和可用降级页面。
- 页面底部展示团队、学校、内容与地图来源、审图号及必要备案信息。

## 13. 内容交付清单

每处景点需要：

- 权威基础信息和史料来源
- 约 180 字口播稿
- H5 详情正文
- 一张代表性头图
- 一至五张精选实拍图片，横竖画幅均可；超过五张时另存视觉预选清单
- 一条约 60 秒竖版讲解视频
- 一张视频封面
- 可选背景音乐或纯语音文件

文件采用“景点名称-素材类型”命名，例如“雨花台-主图.jpg”“雨花台-讲解视频.mp4”。
