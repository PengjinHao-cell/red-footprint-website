# 城市地图缩放与红星命中修复设计

## 1. 背景

南京三个景点必须使用真实经纬度和既有投影结果，不能通过挪动红星解决视觉拥挤。当前红星图案约 42px，但外层透明点击区为 64px；南京三颗星中心距离约 46—49px，因此透明区域互相覆盖，线上已经出现点击“雨花台烈士陵园”却打开“梅园新村纪念馆”的错误。

旧版 3D 地球曾支持滚轮和手势缩放。提交 `b25a8dc` 删除 `GlobeScene`、`globe.gl` 与 `three` 后，这项用户可操作的缩放也被移除。现有 `mapMotion.ts` 仅提供进城和进入详情时的一次性动画缩放，不能由用户控制，也不保存视图。

## 2. 已确认决定

- 采用分层平面缩放，不恢复 3D 地球。
- 红星视觉大小、颜色、形状和跳动动画保持不变。
- 透明点击区从 64px 缩为 44px；红星图案仍约 42px。
- 红星和名称都可单击并直接进入对应详情。
- 支持缩放按钮、电脑滚轮、手机双指和双击放大。
- 关闭详情保留城市地图的缩放与位置。
- 返回全国地图时复位城市地图。
- 经纬度、投影参数、投影结果和红星锚点均不得改变。

## 3. 视觉与命中模型

`CityStarMarker` 拆成三个职责明确的层：

1. 锚点容器：只负责放置真实投影坐标，不接收指针事件。
2. 星体按钮：44px × 44px，内部继续渲染约 42px 的星形。
3. 名称按钮：独立点击入口，最小高度 44px，继续使用现有方向布局。

星体和名称调用同一个 `onSelect(site.id)`，但拥有独立 DOM 按钮，不能依靠事件冒泡。标签若视觉接近，只调整标签方向和引导线，不调整红星锚点。

## 4. 分层缩放架构

城市地图划分为：

- `viewport`：裁切窗口，接收滚轮、双指和双击输入。
- `world`：包含底图和坐标锚点，应用平移与缩放。
- `marker-ui`：随锚点移动，但对自身应用反向缩放，使红星、名称和点击区保持固定屏幕尺寸。
- `controls`：放大、缩小、复位按钮，始终位于地图上方，不参与底图缩放。

视口状态为：

```ts
type CityMapViewportState = {
  scale: number;
  translateX: number;
  translateY: number;
};
```

缩放范围固定为 1—2.5 倍。按钮以地图中心为锚点；滚轮以鼠标位置为锚点；双指以手势中心为锚点；双击在点击位置放大一级。所有换算由纯函数完成，DOM 组件只负责输入和渲染。

## 5. 坐标不变量

以下数据和算法不得修改：

- `src/data/sites.json` 中的景点经纬度；
- `cityMapConfig.ts` 中的 viewBox、投影模式和标定控制点；
- `projectCoordinate()` 的输入、输出和签名；
- `CityStarMarker` 的 `data-anchor-x`、`data-anchor-y`。

缩放只改变视口中的显示矩阵。底图与锚点以相同矩阵移动，因此地理位置关系不变；标记自身反向缩放只抵消 UI 尺寸变化，不改变锚点。

## 6. 状态与转场

用户视口缩放与旅程动画必须使用两套状态：

- 永久视口状态：`--city-scale`、`--city-x`、`--city-y`；
- 临时转场状态：`--motion-scale`。

关闭详情只结束临时转场，永久视口状态保留。返回全国地图会卸载当前城市视口，因此自然复位。动画进行期间禁用景点入口；动画完成或取消后必须恢复。

`prefers-reduced-motion` 只取消动画缓动，不禁用按钮、滚轮或手势缩放。

## 7. 输入行为

- 按钮：每次按 1.25 倍步进放大或缩小；达到边界后禁用对应按钮。
- 滚轮：指针位于地图内时按离散步长缩放，不允许产生页面横向溢出。
- 双指：以两指中心缩放；单指仍用于页面纵向滚动，不抢占常规浏览。
- 双击：以双击位置放大一级。
- 复位：恢复 scale 1、平移 0，并把焦点返回“放大地图”按钮。

## 8. 降级与错误处理

- 浏览器不支持手势时，三个缩放按钮仍可完整操作。
- 城市底图加载失败时继续使用现有文字列表，不显示无意义缩放控件。
- 非有限缩放值或平移值直接回退到初始视图。
- 组件卸载时移除所有指针和滚轮监听，避免返回全国后残留输入。

## 9. 验收标准

1. 分别点击南京三颗红星，详情标题必须与红星一致。
2. 分别点击南京三个名称，详情标题必须与名称一致。
3. 南京点击用例连续运行 10 次无误点。
4. 缩放前后经纬度、投影坐标和 `data-anchor-x/y` 完全一致。
5. 1—2.5 倍范围内红星图案仍约 42px，星体点击区仍为 44px。
6. 按钮、滚轮、双指、双击和复位均通过真实浏览器测试。
7. 关闭详情保留视图；返回全国地图后再次进入城市为初始视图。
8. 390×844、768×1024、1366×768、1920×1080 无横向页面溢出。
9. Desktop Chromium、Pixel Mobile Chromium、iPhone Mobile WebKit 的适用用例全部通过。
10. `npm run verify:release` 通过，构建中不重新出现 `globe.gl` 或 `three`。

## 10. 范围边界

- 不移动红星或修改真实坐标。
- 不恢复 3D 地球。
- 不修改地图图片、内容资料、CloudBase 媒体或部署配置。
- 本轮完成本地实现、测试、验收记录和独立提交；不自动推送或部署。
